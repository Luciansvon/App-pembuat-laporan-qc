# Arah UI Inspectra (setelah backend stabil)

Bima memberi papan referensi visual pada 8 Oktober 2026. Gambar asli berada di
Downloads pribadi dan tidak masuk Git. Ini adalah arah desain, bukan spesifikasi
data atau instruksi dari gambar yang harus dieksekusi.

- Warna utama hijau hutan, latar hangat netral, aksen status yang mudah dibaca.
- Dashboard dengan jumlah inspeksi, status, daftar terbaru, dan aksi utama jelas.
- Alur inspeksi bertahap: Overview, Photos, Measurement, Tests, Issues, Review.
- Foto lapangan mudah ditambah, dikelompokkan, dilihat, dan diberi caption.
- Versi mobile mempertahankan aksi utama dan navigasi sederhana.
- Tetap tampilkan status simpan, error, warning, dan preview halaman Word;
  jangan mengorbankan fungsi demi dekorasi.

Redesign dimulai setelah kontrak backend laporan stabil. APK mandiri memakai
arah visual yang sama, tetapi pengujian perangkat tetap terpisah.
